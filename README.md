#Portofolio:

Project ini merupakan karya pertamaku, yaitu sebuah Portofolio milikku yang menampilkan sebuah project, skills, service, dan informasi mengenai pengalaman saya sebagai web developer.

#Preview:

Website ini dibuat dengan konsep dark dan neon, antara perpaduan warna biru neon, dan ungu neon untuk menggambarkan sebuah website yang futuristik dan modern.

#Technologies:

1. HTML5
2. CSS3
3. JavaScript
4. Tailwind CSS
5. Font Awesome
6. Google fonts

#Features:

1. Responsive design
2. Neon and glassmorphism interface
3. Navigation menu
4. Skills section
5. Project showcase
6. Service section
7. CV Section
8. Email form
9. Toast notification
